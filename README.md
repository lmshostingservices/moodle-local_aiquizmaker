# AI Essay Maker - Moodle Local Plugin

AI-powered WHS essay question generator for Moodle with Moodle XML export.

## Description

AI Essay Maker is a local plugin that generates professional essay questions focused on Workplace Health and Safety (WHS) competencies for Australian RTOs. Questions are generated with complete rubrics and sample answers, ready for import into Moodle question banks.

## Features

- **AI Question Generation**: Creates unique essay questions using GPT-4
- **WHS Focused**: Tailored for Australian workplace safety training
- **3-Point Rubric**: Each question includes hazard, example, and control criteria
- **Industry Specific**: Customise for 19 different industries
- **State Compliance**: Considers state-specific WHS regulations
- **Moodle XML Export**: Direct import to question banks
- **Sample Answers**: Each question includes a model answer
- **Credit-Based**: Pay-per-use model (1 credit per question)

## Requirements

- Moodle 4.0 or later (version 2022041900+)
- PHP 7.4 or later
- Active Essay Grader AI subscription with credits

## Installation

1. Download the plugin ZIP file
2. Log in to your Moodle site as an administrator
3. Go to Site Administration > Plugins > Install plugins
4. Upload the ZIP file or extract to `/local/essaymaker/`
5. Follow the on-screen installation prompts
6. Configure the plugin with your Site ID and API Key

## Configuration

1. Go to Site Administration > Plugins > Local plugins > AI Essay Maker
2. Enter your Site ID (your Moodle site URL)
3. Enter your API Key (obtained from lms-labs.com)
4. Save changes

## Usage

1. Navigate to the AI Essay Maker page (Site Administration or Navigation block)
2. Select your target country and state
3. Choose the industry and provide details
4. Enter the job title and level
5. Add assessment criteria with question counts
6. Click "Generate Questions"
7. Review generated questions with rubrics
8. Download Moodle XML or copy individual questions
9. Import XML into your Moodle question bank


## ⭐ Why this plugin is unlike anything else available

**Generates Moodle XML — not ideas, not prompts, not text to copy**

- Every generic AI quiz tool outputs text you then manually rebuild in Moodle. AI Quiz Maker outputs a .xml file in Moodle Question XML format that imports in one click — categories, question text, marking guide, and feedback fields all correctly structured.
- Questions are built around real workplace scenarios specific to the unit of competency you enter. The AI understands the WHS Act structure (hazard identification, risk assessment, hierarchy of controls) and embeds it into the scenario context, not just mentions it.
- Repeat the generation and you get different scenarios with the same learning outcomes — so question banks grow over time without teacher effort.
